①

▾ 恶化预警

前面两块看的是整个区间的汇总，一个对象前 25 天正常、最近 3 天崩掉会被平均掉。这里把区间切成等长两段（近 N 天 vs 前 N 天）逐个对象比，只报正在变差的，并用 ΔlnACOS = ΔlnCPC − ΔlnCVR − Δln客单 拆出主因，不靠拍脑袋。
②

▾ 广告漏斗诊断

用广告漏斗的三层——曝光 → 点击 → 转化——给每个对象定位卡点：CTR 低说明卡在曝光转点击（主图 / 价格 / 相关性），CVR 低说明卡在点击转下单（详情页 / 库存 / Buy Box / 评价），两者都过线但 ACOS 超过盈亏线则是出价问题。同一棵决策树跑在 ASIN / 广告活动 / 搜索词三种对象上，按卡点分类、按花费排序，点一行看该对象的每日走势。注意判据全部取自广告数据，所以「数据不足」那一类不是没问题，是点击太少还判不了。
诊断阈值 对标基准 站点站点×品牌站点×价格带
③

▾ 投放优化 · 词 / 广告位 / 预算

和上一块的分工：② 看「对象」——ASIN / 广告活动 / 搜索词 各自卡在漏斗哪一环；③ 看「投放设置」——后台里能直接改的四类东西，各自表现如何、该怎么调：烧钱词（哪些搜索词在白烧钱，该否定）、拓词收割（自动跑出来、值得单独建精准组的词）、广告位溢价（首页顶部 / 商品页 / 站外，哪个位效率好该加溢价、哪个该降）、预算受限（哪些活动天天顶到预算、卡住了本可以放的量）。每条都带目标活动 / 广告组，导出后可以直接照着在后台操作。
长期体检 不产生今天的待办，每周看一次就够 · 展开后自动占满整行

▸ 预算天花板 · 边际 ROAS

回答「再加预算还划不划算」。按日把广告花费分档，看每多花 1 元换回多少增量总销售额（边际 ROAS），再和盈亏平衡线 1÷毛利率 比——高于线说明还没到天花板。

▸ 自然表现 · 广告依赖度

把广告拆出去，只看自然销售额 / 自然订单 / 自然会话的周走势 —— 自然线掉，通常比 ACOS 早一两周
